# Penpot Terraform product module
<!-- vale Canonical.007-Headings-sentence-case = YES -->

This folder contains the [Terraform][Terraform] product module for Penpot. It deploys a
ready-to-use Penpot solution with the [Terraform Juju provider][Terraform Juju provider]:

- `penpot`, `redis-k8s` and `s3-integrator` in the Kubernetes model given by `model_uuid`.
- `postgresql` in the machine model given by `database_model_uuid`. The module offers its
  `database` endpoint and integrates Penpot with it across models.

Each bundled dependency is optional. Set `postgresql_integration`, `redis_integration` or
`s3_integration` to an existing application `name` in the Kubernetes model or to an `offer_url`,
and the module integrates Penpot with it instead of deploying its own.

The module doesn't deploy an ingress. Set `ingress_integration` to integrate Penpot with an
existing `ingress` provider, such as `traefik-k8s`, and optionally `smtp_integration` and
`logging_integration` for the optional integrations.

`risk` sets the channel risk of every bundled charm whose `channel` is left unset. Penpot and
`redis-k8s` are published on `edge` only, so set `risk = "edge"` until they are released to
`stable`.

The bundled `s3-integrator` needs its credentials set after deployment with the
`sync-s3-credentials` action.

## Module structure

- **main.tf** - Defines the Juju applications, offers and integrations of the solution.
- **locals.tf** - Derives the charm channels from `risk` and selects the integration targets.
- **variables.tf** - Allows customization of the deployment, including the revision and
  OCI resources of every bundled charm.
- **outputs.tf** - Exposes the deployed `models`, the created `offers` and the deployment
  `metadata`.
- **terraform.tf** - Defines the Terraform and Juju provider versions.

## Using the Penpot product module

Always pin the `?ref=` to a released tag or a commit hash: CC008 does not allow floating
references such as branches.

```text
data "juju_model" "penpot" {
  name  = "penpot"
  owner = "admin"
}

data "juju_model" "database" {
  name  = "penpot-db"
  owner = "admin"
}

module "penpot" {
  source = "git::https://github.com/canonical/penpot-operator//terraform/product?ref=tf-1.0.0"

  model_uuid          = data.juju_model.penpot.uuid
  database_model_uuid = data.juju_model.database.uuid
  risk                = "edge"

  ingress_integration = {
    name     = "traefik-k8s"
    endpoint = "ingress"
  }
}
```
