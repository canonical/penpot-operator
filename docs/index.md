that bridges the gap between designers and developers.

## How this documentation is organised

This documentation follows the [Diátaxis documentation structure](https://diataxis.fr/).

- The [Tutorial](tutorial/getting-started.md) takes you step by step through deploying the Penpot charm for the first time.
- [How-to guides](how-to/index.md) assume basic familiarity with the charm and cover practical tasks for configuring, integrating, maintaining, and contributing to it.
- Reference material provides technical details about [Actions](reference/actions.md), [Configurations](reference/configurations.md), and the [Charm architecture](reference/charm-architecture.md).

## Contributing to this documentation

Documentation is an important part of this project, and we take the same open-source approach to the documentation as the code. As such, we welcome community contributions, suggestions, and constructive feedback on our documentation. See [How to contribute](how-to/contribute.md) for more information.

If there's a particular area of documentation that you'd like to see that's missing, please [file a bug](https://github.com/canonical/penpot-operator/issues).
